# Testing each feature (manual)

- **Blocker:** hold = zero damage. Getting hit starts a 10 s cooldown and shows it.
- **Pill:** 1.5 s progress bar. Heals small + 5 s regen. Stacks.
- **Healer:** thrown item creates a radius that heals the player standing in it, including at own feet.
- **Chains:** fire, hit wall = teleport. Fire, press again in flight = teleport to chain. Hit enemy = large damage; velocity preserved on arrival.
- **Slam:** 3 presses mid-air = fast fall, shockwave pushes dummies away.
- **Crash stop:** run into wall at full speed = stop + freeze + shake.

When a test fails: copy the exact error text and the script name and send both to the agent.
