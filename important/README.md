# Momentum Slicer (working title)

A 3D first-person game in Godot 4 (GDScript) built around momentum, slicing, and a chain harpoon.
Goal: it must feel **impossibly satisfying** to move and hit things.

## For the AI agent: read in this order
1. `AGENTS.md` - rules of engagement
2. `docs/01-design.md` - what the game is (source of truth)
3. `docs/02-setup.md` - environment and project layout
4. `docs/03-architecture.md` - how the code is organised
5. `docs/04-roadmap.md` - the phases; work on ONE phase at a time
6. `docs/05-juice.md` - feel checklist
7. `docs/06-testing.md` - how to verify each phase
8. `docs/07-modding.md` - mod loading, API, data-driven rules
9. `docs/08-tester-tools.md` - dev console, overlays, test scenes

## For the human
Paste `docs/00-agent-prompt.md` into your AI agent, then ask it to start Phase 0.
Commit to git after every phase that works.
